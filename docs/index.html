A deliberate tool for everyday technical work

agentware

An interactive C++ agent for turning a request into inspected files, bounded commands, working notes, and a clear next action. It is built for the work that sits between an office request and a code change.

View source Report an issue

Finding 01

One interactive session, with the work visible.

agentware runs as a single command-line session. It keeps the operator in the loop while it helps examine code, read and write files, run commands, use Git and GitHub helpers, retrieve web content, and talk to a configured model provider.

RuntimeNative C++20 command-line application built with CMake.
Work surfaceFiles, directories, shell commands, repositories, context, and checkpoints.
Model accessProvider credentials are supplied through environment configuration.

Finding 02

Designed for practical requests.

Use it when a request needs more than a chat response but less than an unattended automation system.

  • Trace how a feature, configuration, or incident note maps onto an existing repository.
  • Prepare small code or documentation changes with file context available in the session.
  • Inspect a set of files, preserve useful notes in memory, and return to the work through checkpoints.
  • Work through Git, GitHub, web retrieval, or MCP-connected tooling from one interactive surface.

Method

A reviewable operating sequence.

Receive

Start with a concrete request and select an operating mode or provider.

Inspect

Read the relevant files, repository state, and available context before changing anything.

Act

Use direct commands, file operations, or model-assisted work in the active session.

Record

Keep context, checkpoints, session statistics, and errors available for follow-up.

Start

Build locally.

cmake -S . -B build
cmake --build build
./build/bin/agentware-agent

Boundary

Human judgment remains part of the system.

agentware can access powerful capabilities when configured, including local commands and external providers. Review configuration, credentials, commands, and proposed changes before using them in an important environment. This site describes the repository, not a compliance or security certification.
